# telegram-channel-scraper (راهنمای فارسی)

**[English README](README.md)**

یک ابزار خط‌فرمان (CLI) ساده و مبتنی بر Telethon که تمام پیام‌های یک یا چند
**کانال یا گروه** تلگرام (عمومی یا خصوصی) رو به فرمت JSON/CSV ذخیره می‌کنه —
با قابلیت ادامه‌ی اجرای قبلی (resume)، دانلود اختیاری مدیا، و پشتیبانی چند
کانال/گروه در یک اجرا.

> فقط خواندنی (Read-only): این ابزار فقط پیام‌های کانال/گروهی که خودت
> عضوش هستی رو می‌خونه. هیچ پیامی نمی‌فرسته، ادیت نمی‌کنه، و به هیچ‌جا جوین
> نمی‌شه.

## نکته‌ی مهم: هم کانال، هم گروه

این ابزار محدود به کانال‌های براودکست نیست — روی **گروه‌های معمولی و
سوپرگروه‌ها** (از جمله گروه خصوصی خودت) هم کار می‌کنه. یعنی می‌تونی همین
اسکریپت رو برای گرفتن تاریخچه‌ی پیام‌های یک **گروه شخصی** هم استفاده کنی و
از روی دیتای خروجی، وضعیت سلامت گروه رو بسنجی: میزان فعالیت، فعال‌ترین
اعضا، روند تعامل در طول زمان و امثال آن. کافیه در `CHANNELS` (یا با
`--channel`) آیدی/لینک همون گروه رو بدی — نیازی به تنظیم جدا نیست.

## قابلیت‌ها

- **چند کانال/گروه در یک اجرا** — فلگ `--channel` رو چندبار تکرار کن، یا
  توی `.env` لیست `CHANNELS` رو با کاما جدا کن.
- **ادامه‌ی اجرای قبلی (Resume)** — هر بار که دوباره اجرا کنی، فقط پیام‌های
  **جدیدتر** از آخرین id ذخیره‌شده گرفته و به فایل قبلی اضافه می‌شه. برای
  اجرای کامل از صفر از `--no-resume` استفاده کن.
- **خروجی JSON و/یا CSV** (`--format json|csv|both`).
- **ذخیره مشخصات فرستنده در گروه‌ها** — هرجا تلگرام اجازه بده، آیدی، اسم،
  یوزرنیم و نوع فرستنده ذخیره می‌شه تا AI بتواند تحلیل کند چه کسی چه چیزی
  گفته.
- **دانلود مدیا اختیاریه** (`--download-media`) — به‌صورت پیش‌فرض فقط
  تعداد مدیا (`media_count`) ثبت می‌شه و هیچ فایلی دانلود نمی‌شه.
- **پشتیبانی از آلبوم** — پیام‌های گروهی (چند عکس زیر هم) به یک پست واحد
  ادغام می‌شن.
- **مقاوم در برابر Flood-wait** — وقتی تلگرام محدودیت نرخ اعمال کنه،
  اسکریپت خودش صبر می‌کنه و دوباره تلاش می‌کنه.

## نصب و اجرا (ویندوز / PowerShell)

پاورشل رو توی پوشه‌ای باز کن که فایل‌های `scraper.py` و `.env` داخلش هستند، بعد این دستورات رو بزن:

```powershell
cd "path\to\telegram-channel-scraper"
Get-ChildItem scraper.py, .env
python -m pip install -r requirements.txt
python .\scraper.py
```

> `cd path\to\telegram-channel-scraper` رو با مسیر واقعی پوشه‌ای که پروژه رو
> توش clone/دانلود کردی جایگزین کن. مثلاً اگه پروژه توی
> `F:\telegram-channel-scraper` هست، بنویس: `cd F:\telegram-channel-scraper`
>
> اگر `Get-ChildItem scraper.py, .env` خطا داد، یعنی داخل پوشه‌ی اشتباه
> هستی. فایل `.env` و دستور `python .\scraper.py` باید دقیقاً داخل پوشه‌ی
> خود پروژه باشند، نه پوشه‌ی بالاتر مثل `F:\Telegram app`.
>
> در ویندوز از `python -m pip ...` استفاده کن، نه `pip ...`. این کار
> پکیج‌ها را با همان Python نصب می‌کند که `scraper.py` را اجرا می‌کند؛ حتی
> اگر launcher جداگانه‌ی `pip` به یک Python قدیمی یا حذف‌شده وصل باشد.

## تنظیم فایل `.env`

فایل `.env` از قبل داخل پروژه هست. فقط این مقادیر رو پر کن:

```env
API_ID = 123456
API_HASH = ""
PHONE = "+98"
CHANNELS = ""
```

| کلید | توضیح |
|---|---|
| `API_ID`, `API_HASH` | از https://my.telegram.org وارد شو → بخش «API development tools» → یه اپ بساز → این دو مقدار رو کپی کن |
| `PHONE` | شماره موبایل تلگرامت با کد کشور (مثلاً `+98912xxxxxxx`) — برای لاگین لازمه |
| `CHANNELS` | لیست کانال‌ها **یا گروه‌ها** با کاما جدا (یوزرنیم، لینک، یا آیدی عددی) |

کانال‌ها از `.env` خونده می‌شن و اسکریپت دیگه ازت کانال نمی‌پرسه.
قبل از شروع اسکرپ، اسکریپت از توی ترمینال می‌پرسه:

- عکس‌ها و فایل‌ها دانلود بشن یا نه
- متن پیام‌ها ذخیره بشه یا نه
- خروجی `json` باشه، `csv` باشه، یا هردو

این تنظیمات رو می‌تونی با فلگ‌های کامندلاین هم بدی تا سوال نپرسه (بخش نحوه‌ی اجرا رو ببین).

مقدارِ `CHANNELS` می‌تونه هرکدوم از این فرمت‌ها باشه:

```env
# یوزرنیم عمومی
CHANNELS = "yourchannel"

# لینک عمومی
CHANNELS = "https://t.me/yourchannel"

# لینک دعوت خصوصی (باید از قبل عضوش باشی)
CHANNELS = "https://t.me/+xxxxxxxxxxxx"

# آیدی عددی (برای گروه‌ها/سوپرگروه‌ها معمولاً با -100 شروع می‌شه)
CHANNELS = "-1001234567890"

# چند مورد با هم (کانال + گروه با هم مشکلی نداره)
CHANNELS = "yourchannel,-1001234567890"
```

### لاگین در اولین اجرا — دقیق توجه کن

وقتی برای اولین بار `python scraper.py` رو اجرا کنی:

1. چون `PHONE` رو توی `.env` پر کردی، اسکریپت شماره‌ت رو خودش می‌فرسته و **دیگه ازت شماره نمی‌پرسه**.
2. معمولاً حدود ۱۰ ثانیه طول می‌کشه تا خط وارد کردن کد توی PowerShell نمایش داده بشه.
3. تلگرام یه **کد ورود** به اکانت تلگرامت می‌فرسته؛ معمولاً داخل اپ تلگرام میاد، نه لزوماً پیامک.
4. توی همون پنجره‌ی PowerShell که اسکریپت داره اجرا می‌شه، پیام `Please enter the code you received:` میاد — همون کد رو تایپ کن و Enter بزن.
5. اگه روی اکانتت **رمز دومرحله‌ای (2FA)** فعاله، بعدش رمزت رو هم می‌پرسه.

بعد از این مرحله، یه فایل `.session` ساخته می‌شه و **دفعات بعد دیگه هیچ‌کدوم از این مراحل تکرار نمی‌شه** — اسکریپت مستقیم وصل می‌شه.

این برنامه هک نیست و مشکل امنیتی ذاتی ندارد. ورود از طریق API رسمی تلگرام
انجام می‌شود و خودت با کدی که تلگرام به اکانتت می‌فرستد دسترسی می‌دهی.
اسکریپت فقط خواندنی است: پیام‌های کانال/گروهی را می‌خواند که خودت به آن
دسترسی داری؛ پیام نمی‌فرستد، چیزی را ادیت نمی‌کند و جایی جوین نمی‌شود.

> ⚠️ فایل `.session` مثل یه کلید ورود به اکانتته — هیچ‌وقت جایی آپلود یا شیر نکن.


## نحوه‌ی اجرا

```bash
# همه‌ی مقادیر CHANNELS توی .env رو بگیر و به JSON ذخیره کن
python scraper.py

# یک یا چند کانال/گروه مشخص رو بگیر، بدون نیاز به .env
python scraper.py --channel yourchannel --channel https://t.me/yourgroup

# خروجی CSV رو هم اضافه کن
python scraper.py --format both

# مدیا (عکس/فایل) رو هم دانلود کن (پیش‌فرض خاموشه)
python scraper.py --download-media

# متن پیام‌ها ذخیره نشه و فقط اطلاعات/مدیا ثبت بشه
python scraper.py --no-save-text

# به‌جای ادامه از قبل، کل تاریخچه رو از نو بگیر
python scraper.py --no-resume

# محدود کردن تعداد پیام‌های اسکن‌شده (برای تست سریع)
python scraper.py --limit 200
```

## خروجی چطور ذخیره می‌شه

بعد از اجرا، یک پوشه‌ی `output` در همان مسیری که `python .\scraper.py`
را اجرا کردی ساخته می‌شه. برای هر کانال/گروه، فایل‌ها داخل همان پوشه ذخیره
می‌شن:

- `<name>_posts.json` — آرایه‌ای از پیام‌ها:
  ```json
  {
    "id": 123,
    "date": "2026-07-02T10:00:00+00:00",
    "sender_id": 123456789,
    "sender_name": "Example User",
    "sender_username": "exampleuser",
    "sender_type": "User",
    "text": "متن کامل پیام، بدون هیچ برشی",
    "media_count": 1,
    "media_files": ["123_124.jpg"],
    "reactions": 4,
    "views": 5231,
    "forwards": 12,
    "link": "https://t.me/yourchannel/123"
  }
  ```
- `<name>_posts.csv` — همون فیلدها به‌صورت مسطح (فقط با `--format csv|both`).

اگه `--download-media` رو بزنی، فایل‌ها توی
`output/<name>/media/` ذخیره می‌شن.

اگر قبلاً کانال را بدون مدیا گرفته بودی، توی `.env` مقدار
`DOWNLOAD_MEDIA = "true"` رو بذار و دوباره اسکریپت رو اجرا کن. برنامه
پیام‌های قبلی را هم برای پیدا کردن مدیا اسکن می‌کند و فایل‌هایی که از قبل
وجود دارند را دوباره دانلود نمی‌کند.

## نکات و محدودیت‌ها

- تشخیصِ resume بر اساس **id پیام** انجام می‌شه؛ اگه یه پیام بعد از
  ذخیره‌شدن ادیت بشه، اجرای بعدی اون ادیت رو نمی‌گیره (فقط پیام‌های جدید
  گرفته می‌شن).
- مشخصات فرستنده برای پیام‌هایی ذخیره می‌شه که از این نسخه به بعد گرفته
  می‌شن. اگر قبلاً خروجی گرفته بودی و می‌خوای مشخصات فرستنده هم به فایل‌ها
  اضافه بشه، یک بار با `--no-resume` دوباره خروجی بگیر.
- برای کانال/گروه خصوصی، اکانتی که با آن لاگین کردی باید از قبل عضو باشه.
- روی کانال/گروه‌های بزرگ صبور باش — اسکریپت محدودیت‌های flood-wait تلگرام
  رو رعایت می‌کنه و خودش صبر می‌کنه.
- فایل `.session` مثل کلید ورود به اکانتته و توسط `.gitignore` از
  کامیت‌شدن مستثنا شده؛ هیچ‌وقت این فایل رو جایی آپلود یا شیر نکن.
